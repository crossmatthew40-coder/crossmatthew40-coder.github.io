Accessibility

High Style Match is being built so its core photography workflow can be used with a keyboard, screen-reader friendly labels, visible focus states and strong foreground/background contrast.

Current measures

  • High-contrast monochrome interface.
  • Visible keyboard focus indicators.
  • Skip-to-content link on supported pages.
  • Accessible labels added to unlabeled buttons and form controls.
  • Alt text or descriptive fallback labels for interface images and previews.
  • Reduced-motion support for users who request it in their device settings.
  • Native HTML form controls wherever practical.

Known limitations

Some advanced photography interactions, file-system pickers and third-party browser controls depend on the operating system and browser. The native desktop and iPad builds will require separate accessibility testing before release.

Report a problem

If something is difficult to use with a keyboard, screen reader, zoom or other assistive technology, contact support@highstylegroup.co.uk and include the page, device and browser.
