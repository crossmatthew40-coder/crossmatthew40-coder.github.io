Missing-shot notifications

If the current shot-list requirement has no captured image for the selected time, Match warns you in the app and can send a browser notification. Moving on from a requirement with zero images also triggers an immediate warning.

What is saved

New tethered files are imported into the same High Style Match project and stored in the same local browser database used by Photographs. RAW + JPEG files with the same filename stem are paired as one capture where possible.
